Migrate Vehicle & Maintenance Data

This process extracts relational data from MariaDB and transforms it into a Denormalized Document Structure in MongoDB.

Migration Steps:

  • 1. Wipe existing vehicle_maintenance collection in MongoDB.
  • 2. Perform SQL JOIN on MariaDB (Vehicle + Station + MaintenanceLog).
  • 3. Map flat SQL rows into Nested Java Objects (Denormalization).
  • 4. Perform Bulk Insert into MongoDB.
